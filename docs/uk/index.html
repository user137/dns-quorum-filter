Локальний DNS-over-HTTPS фільтр для Windows

Що блокувати, вирішує кворум, а не один провайдер.

Браузер надсилає DNS-запити невеликому серверу на вашому ж комп'ютері (127.0.0.1). Для кожного домену той паралельно питає кілька незалежних фільтрувальних DNS-провайдерів і блокує домен, якщо хоч один із них каже «блок». Один скомпрометований чи помилковий провайдер сам загрозу не пропустить.

Що це, а що ні

Фільтр на рівні DNS

Шкідливе ПЗ, фішинг, реклама, трекери і (якщо ввімкнете) вміст для дорослих блокуються за доменом ще до з'єднання.

Не розширення-блокувальник реклами

Немає вибору елементів сторінки чи косметичної фільтрації. Працює поряд з uBlock Origin або схожим розширенням, а не замість нього.

Лише браузери

Фільтрує браузери, які ви на нього налаштуєте. Інші програми й далі користуються системним DNS: системне налаштування навмисно не чіпаємо, щоб збій не поклав вам усю мережу.

Відкрито для перевірки

Кожне твердження на цій сторінці можна перевірити в коді, специфікації й тестах на GitHub.

Як працює фільтрація

Кожен запит проходить ті самі перевірки згори донизу. Перша, що дає остаточну відповідь, вирішує; решта пропускаються.

  1. Ваш список дозволених. Домени з нього завжди дозволені.
  2. Ваш список заблокованих і, за бажанням, публічні списки блокування (реклама, трекери, загрози; типово вимкнені). Блокуються без жодного мережевого запиту.
  3. Доменні зони країн, які ви вирішили блокувати, наприклад уся зона .xx.
  4. Кеш. Нещодавно перевірений домен отримує відповідь із пам'яті.
  5. Лише популярні сайти (за бажанням, типово вимкнено): домени поза обраними зонами блокуються.
  6. Кворум. Увімкнені провайдери питаються паралельно. Якщо хоч один каже «блок», домен блокується. Одразу після встановлення: Quad9, Cloudflare (шкідливе ПЗ) і AdGuard DNS; список можна змінити.
  7. Перевірка країни (за бажанням): дозволена відповідь, чия IP-адреса в заблокованій вами країні, теж блокується.

Заблокований домен отримує адресу 0.0.0.0 / ::, а не «такого домену немає»: дехто з браузерів на «такого домену немає» тихо питає інший резолвер, і фільтр опиняється в обході.

Компроміси — одразу й чесно

Ваші запити бачать кілька провайдерів

Щоб був кворум, кожен запит поза кешем іде до кожного увімкненого провайдера і до нефільтрованого довідкового DNS. Більше третіх сторін бачать, які домени ви відкриваєте, — в обмін на ширше покриття загроз. Сторінка налаштувань показує, хто саме. Див. політику приватності.

Сертифікат лише для 127.0.0.1

Браузери говорять DNS-over-HTTPS лише з довіреним сервером, тому застосунок встановлює самопідписаний сертифікат, дійсний тільки для 127.0.0.1. Це навмисно не центр сертифікації: викраденим ключем можна підробити цей локальний сервер, а не інші сайти.

Коли фільтри недоступні

Типово застосунок пропускає відповідь, щоб не ламати перегляд, а іконка в треї та сторінка налаштувань кажуть, що фільтрація неповна. Можна натомість увімкнути блокування в такому разі.

Встановлення

Кожен реліз на сторінці Releases має MSIX-пакет. Поки він підписаний тестовим сертифікатом, тож Windows треба один раз довірити цей сертифікат. Це й встановлення робить допоміжний скрипт.

  1. Завантажте dns-quorum-filter.msix, dns-quorum-filter.cer і Trust-TestCert.ps1 в одну теку.
  2. У цій теці виконайте: 
    powershell -ExecutionPolicy Bypass -File .\Trust-TestCert.ps1 -Install
    Скрипт попросить права адміністратора, довірить сертифікат пакета й встановить застосунок. За бажанням спершу прочитайте його: він короткий і на звичайному PowerShell.
  3. Один раз запустіть DNS Quorum Filter з меню «Пуск». Автозапуск разом із Windows реєструється лише після цього першого запуску.
  4. Майстер першого запуску запропонує довірити локальний сертифікат для 127.0.0.1. Погодьтеся, потім підключіть браузер (наступний розділ).

Перед видаленням скористайтеся меню трею → Повністю видалити. Windows не запускає коду застосунку, коли видаляє MSIX-пакет, тож локальний сертифікат і збережені ключі треба прибрати заздалегідь.

Підключення браузера

У налаштуваннях безпечного DNS (DNS-over-HTTPS) браузера оберіть власного провайдера з цією адресою (8443 — типовий порт): 

https://127.0.0.1:8443/dns-query

Сторінка налаштувань застосунку показує ті самі кроки для браузера, в якому її відкрито, з кнопкою «Копіювати».

Chrome

chrome://settings/security → «Використовувати безпечний DNS» → «Власний».

Edge

edge://settings/privacy/security → «Використовувати захищену службу DNS» → «Виберіть постачальника послуг». Якщо перемикач сірий зі значком портфеля, Edge вважає себе керованим організацією і змінити це не дасть; список політик — edge://policy.

Brave

brave://settings/security → «Використовувати захищений DNS-сервер» (уже ввімкнено) → «Додати власного постачальника».

Opera

opera://settings/system → увімкніть «Використовуйте DNS-поверх-HTTPS замість параметрів DNS системи» → останній пункт списку, без назви, з полем вводу.

Vivaldi

vivaldi:settings/network/ → «DNS через HTTPS» → «Інший провайдер DNS». Зелена галочка означає, що Vivaldi прийняв адресу.

Firefox

about:preferences#privacy → «DNS через HTTPS» → лише «Максимальний захист» → «Обрати постачальника» → «Власний». У «Посиленому захисті» Firefox на кожному заблокованому сайті тихо переходить на системний DNS, і сайт відкривається.

LibreWolf

Не підтримується: не довіряє сертифікатам зі сховища Windows.

Якщо сайт просить доступ до «інших застосунків і служб на цьому пристрої», оберіть «Блокувати».

З таким дозволом сайт міг би надсилати запити локальній службі: за часом відповіді вгадувати, які сайти ви нещодавно відкривали, і дописувати рядки в її журнал. Без дозволу всі п'ять перевірених браузерів (Chrome, Edge, Brave, Opera, Firefox) такі запити не пропускають.

Перевірка, що працює

  1. Відкрийте сторінку налаштувань https://127.0.0.1:8443/admin/ui напряму. Статус угорі каже, чи фільтрація ввімкнена і коли браузер востаннє надіслав запит.
  2. Додайте там нешкідливий домен до списку заблокованих і відкрийте його. Браузери на Chromium покажуть ERR_ADDRESS_INVALID, Firefox — «Не вдається знайти сайт». У журналі в ту саму мить цей домен позначено заблокованим.
  3. Приберіть домен зі списку заблокованих.

Відомі обмеження

  • Поки лише Windows. macOS і Linux заплановано.
  • Фільтруються лише браузери, налаштовані як описано вище.
  • Firefox — лише в режимі «Максимальний захист»; LibreWolf не підтримується.
  • Пакет підписаний тестовим сертифікатом до виходу в Microsoft Store.
  • Інтерфейс — 37 мовами; 35 із них — машинний переклад, ще не перевірений носіями мови.
